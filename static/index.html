    Common questions about Oralyze, autonomous viva voce evaluation, and engineering architecture.

    Oralyze, स्वायत्त मौखिक परीक्षा मूल्यांकन, और सिस्टम आर्किटेक्चर से जुड़े सामान्य प्रश्न।

    What is Oralyze and how does it improve academic viva voce examinations? Oralyze क्या है और यह पारंपरिक मौखिक (viva) परीक्षाओं से कैसे बेहतर है? ▼
    Oralyze is an autonomous, voice-interactive AI viva voce examiner that automates and standardizes oral assessments. Traditional viva exams consume immense faculty hours and suffer from subjective grading variance. Oralyze speaks examination questions aloud, transcribes student oral responses in real time, and leverages IBM Granite LLMs alongside Watson acoustic speech analytics to produce fair, multi-dimensional rubric scorecards evaluating both conceptual mastery (70%) and speech fluency (30%).
    Oralyze एक स्वचालित, वॉयस-इंटरएक्टिव AI मौखिक परीक्षा प्रणाली है जो शैक्षणिक viva voce परीक्षाओं को निष्पक्ष और मानकीकृत बनाती है। पारंपरिक परीक्षाओं में शिक्षकों का अत्यधिक समय लगता है और मूल्यांकन में मानवीय भिन्नता आ सकती है। Oralyze प्राकृतिक भाषा में प्रश्न बोलकर पूछता है, छात्र के उत्तर को रियल-टाइम में ट्रांसक्राइब करता है, और IBM Granite व वॉटसन स्पीच एनालिटिक्स के माध्यम से विषय ज्ञान (70%) और बोलने की प्रवाहशीलता (30%) का वस्तुनिष्ठ स्कोरकार्ड तैयार करता है।
    Can Oralyze function offline without an active backend server? (Demo Mode) क्या Oralyze बिना इंटरनेट या बिना बैकएंड सर्वर के भी काम कर सकता है? (डेमो मोड) ▼
    Yes! Oralyze features a unified client data layer (static/js/api.js) that runs 100% in-browser on static hosting like GitHub Pages. Using the browser's native Web Speech API and 35 pre-bundled engineering curriculum questions, you can instantly test and experience complete oral examination workflows without deploying any backend server or configuring API keys.
    हाँ! Oralyze में एक एकीकृत डेटा लेयर (static/js/api.js) है जो GitHub Pages जैसी स्टेटिक होस्टिंग पर 100% ब्राउज़र के अंदर ऑफलाइन चलता है। ब्राउज़र के नेटिव Web Speech API और 35 पूर्व-लोड किए गए इंजीनियरिंग प्रश्नों की मदद से आप बिना किसी सर्वर या API की के तुरंत लाइव मौखिक परीक्षा का अनुभव कर सकते हैं।
    How are student oral answers scored? (Content Depth vs Delivery Fluency) छात्र के मौखिक उत्तर का मूल्यांकन कैसे किया जाता है? (विषय ज्ञान बनाम प्रवाहशीलता) ▼
    Examinations are evaluated across two mathematically isolated dimensions:
    • Conceptual Depth (70%): Validates Bloom's taxonomy alignment, factual technical key points, and architectural clarity.
    • Delivery Fluency (30%): Analyzes speaking rate (ideal pacing: 110–160 WPM), filler word deductions ('um', 'uh', 'like'), and hesitation pauses exceeding 2 seconds.
    मूल्यांकन को दो स्वतंत्र भागों में विभाजित किया गया है:
    • विषय ज्ञान एवं सटीकता (70%): ब्लोम टैक्सोनॉमी, तकनीकी मुख्य बिंदु और वैचारिक स्पष्टता की जांच करता है।
    • बोलने की प्रवाहशीलता (30%): बोलने की गति (आदर्श गति: 110–160 शब्द प्रति मिनट), अनावश्यक भराव शब्द ('um', 'uh', 'like') और 2 सेकंड से लंबे ठहराव (hesitation pauses) पर अंक निर्धारित करता है।
    How do teachers create viva rooms and how do students join? शिक्षक मौखिक परीक्षा कक्ष (viva room) कैसे बनाते हैं और छात्र कैसे जुड़ते हैं? ▼
    Teachers navigate to the Create Viva tab and enter a natural language prompt (e.g., "Operating Systems 5 questions on Scheduling"). The system generates a unique 6-character room code (such as A7K2QX). Students visit the Join Viva screen, enter the 6-character code, and immediately begin their acoustic viva session.
    शिक्षक Create Viva टैब में जाकर किसी भी विषय का प्रॉम्प्ट दर्ज करते हैं (उदा. "Operating Systems 5 questions on Scheduling")। सिस्टम एक 6-अक्षरों का यूनिक रूम कोड (जैसे A7K2QX) जनरेट करता है। छात्र Join Viva स्क्रीन पर जाकर वही कोड डालते हैं और तुरंत अपनी मौखिक परीक्षा शुरू कर सकते हैं।
    How long does audio recording run and when does it stop? माइक्रोफ़ोन रिकॉर्डिंग कितने समय तक चलती है और यह कब बंद होती है? ▼
    Each question allows an acoustic capture window of up to 90 seconds. Once the 90-second threshold is reached, recording stops automatically and submits for evaluation. Students can also submit earlier at any time by tapping the center mic button or clicking Submit Answer.
    प्रत्येक प्रश्न के उत्तर के लिए अधिकतम 90 सेकंड का समय मिलता है। 90 सेकंड पूरे होते ही रिकॉर्डिंग अपने आप बंद होकर मूल्यांकन के लिए सबमिट हो जाती है। छात्र चाहें तो बीच में कभी भी माइक पर दोबारा क्लिक करके या Submit Answer बटन दबाकर पहले भी उत्तर जमा कर सकते हैं।

    Does Oralyze support answers spoken in Hindi or mixed languages (Hinglish)? क्या छात्र हिंदी या हिंग्लिश (मिश्रित भाषा) में मौखिक उत्तर दे सकते हैं? ▼
